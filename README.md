# Tabs
This project is based on a **problem statement from** **[roadmap.sh](https://roadmap.sh/projects/simple-tabs)**.
It is a simple tabs component built using **HTML, CSS, and JavaScript**. The project focuses on practicing basic DOM manipulation and event handling in JavaScript.
The interface contains four tabs, with the first tab active by default. When a user clicks on another tab, the currently displayed content is hidden and the selected tab's content is displayed.

## 🚀 Features
The project includes:
- Interactive tabs and first tab active by default
- Click-based tab switching
- Dynamic content visibility
- DOM manipulation using JavaScript
- Event handling using click events
- Responsive design using CSS media queries
- No external libraries or frameworks

## 🎯 Goals of this project are:
- Understand how to select HTML elements using JavaScript.
- Practice adding event listeners to elements.
- Learn how to handle click events.
- Practice manipulating CSS classes using `classList`.
- Understand how to show and hide elements dynamically.
- Use `data-*` attributes to connect tabs with their corresponding content.
- Create a responsive tabs component using HTML and CSS.

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript

## ⚡ Deployment Instructions
### 1. Run Locally
1. Clone the repository by downloading the zip file from your GitHub repository.
2. Open `index.html` in your browser.

### 2. Deploy on GitHub Pages (Recommended ✅)
1. Push your project to a GitHub repository.
2. Go to **Repository Settings > Pages**.
3. Under **Branch**, select `main` (or `master`) and `/ (root)`.
4. Click **Save**.
5. Your Tabs component will be live on GitHub Pages.
